# 智能体协作记录

本项目使用 AI 助手加速代码骨架与文档，但口径、规矩、验收测试与门槛由项目负责人审定。
下面记录关键提示词的写法要点，以及 AI 交回后由人工发现并修正的问题。

## 关键提示词（目标 / 只做 / 不做 / 完成标准）

1. **实现特征选择器**：目标=训练与推理共用同一列选择；只做=按 `features.yaml` 选列并校验缺列；
   不做=不做缩放不做编码（交给各自 Pipeline）；完成标准=缺列与缺失都抛 `FeatureContractError`，有单元测试。
2. **实现训练编排**：目标=基线+候选、验证选 champion、测试只评估一次；只做=报告与门禁；
   不做=不做服务、不碰测试集调参；完成标准=`reports/evaluation.{json,md}` + 三条门禁。
3. **实现可加性解释**：目标=基准值+贡献=原始输出；只做=逻辑回归线性与 LightGBM TreeSHAP；
   不做=不引入 shap 库；完成标准=两模型都对得上 `raw_score`，有测试。
4. **实现模型包**：目标=别人拿去能用、用错会被拦；只做=joblib+metadata 与加载核对；
   不做=不做版本注册表；完成标准=特征/依赖不符拒绝加载。
5. **实现质量门**：目标=一条命令、出错变红；只做=ruff+format+mypy+pytest；
   不做=不接远程 CI；完成标准=全绿返回 0，门槛只写一处。

## AI 写错、我发现并修正的实例

1. **切片门禁用 PR-AUC 跨组比较（方法学错误）**：报告显示 baseline 切片 PR-AUC 差距 0.746，
   一度以为模型在高基线组失效。人工核对发现：各组正例率 0.59/0.12/0.015，PR-AUC 下界就是正例率，
   跨组比较无效；改看 ROC-AUC（0.724/0.697/0.707，几乎持平），门禁改用 ROC-AUC 并写 ADR-0005。
   防止再犯：把“PR-AUC 不可跨组比”写进报告渲染与 design.md 局限。
2. **名额制用固定阈值套到测试集（语义错误）**：初版把验证集分数阈值固定应用到测试集，选中比例只有 6.6%、
   召回偏低。人工核对后改为批内 Top-K（名额固定），单条才用等效阈值，写 ADR-0006。
   防止再犯：在 `decision_outcome` 与报告中同时给出选中比例，偏离 K 一眼可见。
3. **CLI 在 Windows 控制台因 GBK 编码崩溃**：`vtrain prepare` 打印含 `²` 的 JSON 时
   `UnicodeEncodeError`。人工定位后在 `main()` 里把 stdout 切到 UTF-8。
   防止再犯：CLI 启动即 reconfigure，README 不需额外设置环境变量。
