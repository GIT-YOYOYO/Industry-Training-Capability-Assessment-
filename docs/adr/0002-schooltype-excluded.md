# ADR-0002：机构类型 schooltype 不入模（公平性）

## 背景

`schooltype` 是培训中心类型（学校级常量），与结果 `y` 强相关（类型 0 均值 0.91，类型 4 均值 -1.81）。
放进模型能提升预测力。

## 决定

不把 `schooltype` 作为特征。模型只用人人都有的基线测评 x1–x5。

## 后果与代价

- 模型对任何中心都可迁移，不会“因为你是某类机构而系统性给更高风险”。
- 代价是放弃一部分预测力（但实测逻辑回归并未因去掉它而明显变差，信号主要在线性维度上）。
- `schooltype` 仍用于**评估切片**（看模型在不同机构上是否一致），但不进模型。
