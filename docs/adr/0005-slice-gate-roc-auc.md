# ADR-0005：切片门禁改用 ROC-AUC（PR-AUC 受正例率影响）

## 背景

最初的切片门禁用“组间 PR-AUC 差距”，结果按基线三分位切时差距 0.746（低组 0.79、高组 0.048）。
但这是**正例率效应**：低基线组正例率 0.59、高基线组仅 0.015，而 PR-AUC 的下界就是正例率。
同一模型在各组的 ROC-AUC 是 0.724 / 0.697 / 0.707，几乎持平。

## 决定

切片门禁指标改为 ROC-AUC（对正例率不敏感），门槛 0.20；报告同时展示 PR-AUC 与 lift（PR/正例率）供解读。
这不是“放宽门槛”，而是**用对指标**——用 PR-AUC 跨组比较在方法学上是错的。

## 后果与代价

- 基线切片的 ROC-AUC 差距 0.027，门禁通过，反映模型在不同基线人群上确实一致。
- 机构类型切片差距 0.178，逼近门槛，如实暴露 `schooltype=0` 组较弱（n 小、正例率低），列入局限。
- 代价：门禁对“头部排序”不敏感；头部质量另由主指标 PR-AUC 与 Top-K 召回保障。
