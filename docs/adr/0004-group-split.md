# ADR-0004：按培训中心分组切分，中心互不相交

## 背景

同一培训中心的学员高度相似：基线能力 `x` 的组内相关系数 ICC≈0.815，结果 `y` 的 ICC≈0.585。

## 决定

用 `GroupShuffleSplit` 按 `schoolid` 分组切分 train/val/test，三个集合的中心互不相交
（由 `assert_disjoint` 强制断言）。测试集是“没见过的中心”。

## 后果与代价

- 指标更接近真实上线（新中心），避免因同中心学员跨切分而高估泛化。
- 代价：测试集中心的构成与训练集不同，正例率有波动（test 27.8% vs train 25.1%）；
  单条推理无法再用 `schoolid`（它也没进模型）。
