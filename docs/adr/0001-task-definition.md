# ADR-0001：任务定义为“不达标风险”二分类，主指标 PR-AUC

## 背景

数据是一个连续结果 `y` 和 5 个基线维度。业务问题是“名额有限的强化班该给谁”。
预测一个具体分数不好直接转成名额决策；分类则能直接对应“谁需要辅导”。

## 决定

把 `y <= 训练集 25% 分位` 定义为“不达标”（正例），做二分类。主指标 PR-AUC，
辅助 ROC-AUC、Top-K 召回/精确率、Brier。

## 后果与代价

- 直接产出可决策的“是人/不是人”，与名额制天然对齐。
- 25% 分位是一个操作化定义，并非外部权威标准；换阈值会改变正例率，需重新评估。
- PR-AUC 兼顾头部排序，但会受正例率影响（见 ADR-0005 的切片处理）。
