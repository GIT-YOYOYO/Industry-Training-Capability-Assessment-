# ADR-0006：名额制按批内 Top-K，单条用验证集等效阈值

## 背景

“名额制”有两种语义：按批取前 K%（名额固定），或按固定风险阈值（跨批人数浮动）。
最初把验证集分数阈值固定套到测试集，结果测试集只选中 6.6%、召回偏低——因为不同中心分数分布不同。

## 决定

- 批量评估/部署：按**批内 Top-K**（取分数最高的 10%），名额固定。
- 单条/小批量推理：没有批次语境，用验证集等效阈值（0.9663）判定；阈值随模型包保存。

## 后果与代价

- 名额语义正确：测试集选中比例 10.0%、召回 30.4%、精确率 84.3%。
- 代价：单条推理的“是否入选”会因当批整体水平而略有偏差；批量场景应优先用 Top-K。
- 模型包同时存 `k_fraction` 与等效 `threshold`，两种用法都能复现。
